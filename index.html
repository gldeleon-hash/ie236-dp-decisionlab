You manage an electric forklift in a warehouse. At the start of each shift, choose an integer amount of battery energy to purchase. The battery then supplies the shift's energy demand. Your mission is to complete all 10 shifts while minimizing total charging cost.

Dynamic Programming solver

This section solves every feasible battery state for every shift by backward recursion. Use it after completing your manual work. This is a self-reveal control, not a secure instructor lock: students with the file can access its code.

Value function: Vₜ(s) = minₓ { pₜx + Vₜ₊₁(s + x − Dₜ) }, over integer x satisfying 0 ≤ x ≤ 8 − s and s + x ≥ Dₜ. Boundary: V₁₁(s)=0.

Understand the recursion

At the last shift, calculate what it costs to finish from each possible battery level. Then solve Shift 9 using the best costs already calculated for Shift 10. Repeat back to Shift 1. The solver records both the lowest remaining cost and the charging action producing it.

Reflect and explain

  1. Is purchasing only the energy needed immediately always the cheapest strategy? Explain.
  2. What makes the battery level a sufficient state for this deterministic problem?
  3. What do the value function and optimal policy each tell us?
  4. How would the transition and Bellman equation change if next shift's demand were uncertain?

Instructor note: This version has public, fixed parameters and is intended for deterministic practice and verification. A separate stochastic extension can add demand distributions and decisions that must be made before outcomes are revealed.
